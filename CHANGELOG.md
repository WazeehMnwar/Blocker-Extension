# Changelog

## 2.0.0

- Replaced per-page timers with centralized, persisted clocks and budgets.
- Added default lockdown, exact domain/subdomain rules, schedules, and approved domains.
- Added manually activated weekend, emergency, and music allowances that count open entertainment tabs once and preserve unused time.
- Added a shared YouTube timer, editable keyword groups, and distinct keyword/timer bypass behavior.
- Redesigned the popup and added a responsive dashboard, configurable block screen, Need Help walkthrough, promises, tasks, and resource library.
- Added measured weekly reports, historical comparisons, and automatic report delivery on startup.
- Added settings phrase protection, v1 migration backup, configuration import, and data export.
- Added portable Firefox/Chromium packaging, source verification, and automated rule/background/interface checks.

Initial configurable defaults: emergency pool resets weekly; music uses its own daily pool; Instagram shares the general entertainment allowance. Saved-resource priority remains undefined and follows normal rules.
